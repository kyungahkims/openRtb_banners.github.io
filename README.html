Google Frame RTB

이 프로젝트는 구글 프레임 RTB(Real-Time Bidding) 광고 배너 개발을 위한 표준 템플릿 및 가이드입니다.

📝 주요 특징

  • 통합 파일 관리: 할인 상품과 비할인 상품을 하나의 HTML 파일로 통합하여 관리합니다.
  • 배너 사이즈 변수 분리: 각 배너 파일의 상단 CSS :root에 해당 배너의 고정 규격(--width, --height)을 명시적으로 분리하여, 사이즈 정보를 한눈에 파악하고 관리하기 쉽도록 구성했습니다.
  • 비상품 배너의 유연한 대응: 비상품(브랜드/프로모션) 배너에 들어갈 이미지는 백단에서 조건 및 우선순위에 따라 동적으로 결정되어 주입됩니다. contain 속성을 통해 이미지 비율이 배너 규격과 맞지 않아도 잘림 없이 여백과 함께 온전하게 노출됩니다.
  • 에러 방어 로직: 상품 이미지 로드 실패 시 전체 배너를 대체 배너로 전환하여 빈 화면(엑스박스)이 노출되는 것을 방지합니다.

🎨 1. 상품 배너

  • 이미지 핏(Fit): 상품 이미지는 object-fit: cover;가 적용되어 있어, 지정된 영역을 빈틈없이 꽉 채우도록 렌더링됩니다.
  • 웹 폰트: 배너 내 텍스트는 Pretendard 폰트(v1.3.9 CDN)를 기본으로 사용합니다.
  • 상품 배너 변수:


항목 변수명 설명
로고 {{logo}} 브랜드 또는 상점 로고 이미지 URL (클릭 시 {{purl1}}로 이동)
상품 클릭 URL {{purl1}}, {{purl2}} ... 개별 상품 클릭 시 이동할 랜딩 페이지 URL
상품 이미지 {{img1}}, {{img2}} ... 상품 이미지 URL
상품명 {{pnm1}}, {{pnm2}} ... 상품 이름
원가 {{price1}}, {{price2}} ... 상품의 원래 가격
할인가 {{price2_1}}, {{price2_2}} ... 할인된 상품 가격
할인율 {{discount1}}, {{discount2}} ... 상품 할인율 (%)
상품 고유 코드 {{pcode1}}, {{pcode2}} ... 상품의 고유 식별 코드 (주로 에러 트래킹용으로 사용)
가격 영역 클래스 {{box1}}, {{box2}} ... 일반가/할인가 여부에 따라 가격 영역(.price_box)의 디자인을 분기하기 위한 CSS 클래스명
노출 추적 태그 {{wp_imgtag}} 배너 노출(Impression) 트래킹을 위한 이미지 픽셀 태그
시스템 변수 {{HTTP}}, {{HTTP_DR}}, {{UUID}}, {{USER}}, {{ITL_TP_CODE}} 에러 로깅 및 모비온 인포 로고(linfo.php) 링크 등에 사용되는 광고 서버 시스템 변수

🖼️ 2. 비상품 배너 (Auto 형식)

상품 데이터를 보여주지 않는 비상품 배너의 경우, 하나의 HTML 파일로 관리하며(Auto 형식) 사이즈 변수만 변경하여 다양한 규격을 대응합니다.

  • 동적 이미지 주입: 백단(서버) 로직에서 조건(우선순위 등)에 따라 배너에 노출될 이미지가 동적으로 결정되어 주입됩니다.
  • 이미지 핏(Fit): 이미지는 object-fit: contain; 처리되어 있어, 백단에서 주입된 이미지의 실제 사이즈(비율)가 배너의 고정 규격과 맞지 않더라도 이미지가 잘리지 않고 여백을 남긴 채로 온전히 노출됩니다.
  • 비상품 배너 변수:

    항목 변수명 설명
    배너 클릭 URL {{purl}} 배너 클릭 시 이동할 랜딩 페이지 URL
    배너 이미지 {{img}} 비상품 배너 이미지 URL
  • 설정 예시: 
    :root {
    --width: 300px;
    --height: 250px;
}

🤖 3. 상품 배너 오토 프레임

여러 사이즈별로 개별 파일을 만들지 않고, 하나의 파일(openRtbAuto.html)로 모든 광고 규격에 대응하는 다이내믹 오토 템플릿입니다.

  • 웹 폰트: 배너 내 텍스트는 Archivo 폰트(Google Fonts CDN)를 기본으로 사용합니다.
  • 자동 레이아웃 변환: 광고 서버에서 넘어오는 가로({{w}}), 세로({{h}}) 사이즈와 비율을 스크립트가 스스로 계산하여, 그에 맞는 최적의 클래스(layout_square (정방형), layout_mobile (모바일형), layout_horizontal (가로형), layout_vertical (세로형))를 부여해 레이아웃을 자동 변환합니다.
  • 이미지 패닝(Panning) 효과: 상품 이미지의 비율과 배너 규격이 심하게 맞지 않아 이미지가 크게 잘릴 경우(비율 차이 30% 이상), 이미지가 좌우 또는 상하로 부드럽게 움직이는 패닝 애니메이션이 자동으로 작동하여 상품의 전체적인 형태를 보여줍니다.
  • 노출 상품 개수 유연성: 배너의 비율에 따라 상품 1~2개가 자동 노출됩니다. 스크립트 내부의 주석 처리를 통해 1개만 고정으로 나오게 하거나, 비율에 따라 1~2개가 나오도록 손쉽게 설정할 수 있습니다.
  • 오토 프레임 전용 변수:

    항목 변수명 설명
    배너 가로 사이즈 {{w}} 현재 노출될 배너의 동적 가로(Width) 픽셀 크기 (예: 300)
    배너 세로 사이즈 {{h}} 현재 노출될 배너의 동적 세로(Height) 픽셀 크기 (예: 250)
    상품 데이터 배열 {{productList}} 스크립트에서 동적 렌더링을 위해 서버에서 주입해주는 JSON 객체 배열 데이터입니다.
    [배열 내부 주요 속성(Property) 명세]
    • img : 상품 이미지 URL
    • purl : 상품 클릭 이동 URL
    • pnm : 상품명
    • price : 원래 가격 (일반 배너의 {{price1}}에 대응)
    • prdt_prmct : 할인 가격 (일반 배너의 {{price2_1}}에 대응)
    • dc_rate : 할인율 (일반 배너의 {{discount1}}에 대응)
    • pcode : 상품 고유 코드
    • advrtsReplcCode : 가격 영역 대체 텍스트 표기 코드 (01, 02, 03)
    • advrtsReplcNm : 대체 표기될 텍스트명
    ※ 기타 시스템 변수({{wp_imgtag}}, {{HTTP}}, {{UUID}} 등)는 상단 일반 배너와 동일하게 사용됩니다.

⚠️ 4. 이미지 에러 처리

네트워크 문제 등으로 상품 이미지가 1개라도 정상적으로 로드되지 않을 경우, 광고 지면의 퀄리티를 유지하기 위해 배너 전체를 대체 배너(모비온 광고)로 전환합니다.
또한, 브랜드 로고({{logo}}) 이미지 로드에 실패할 경우 빈 공간이나 엑스박스 대신 모비온 로고가 대체 노출되도록 처리되어 있습니다.

  • 테스트 방법: 브라우저 개발자 도구(Console)에서 아래 스크립트를 실행하여 이미지 로드 에러 상황을 강제로 발생시킬 수 있습니다. 
    document.querySelector('.img').dispatchEvent(new Event('error'));
  • 트래킹: 에러 발생 시 {{pcode}} 변수를 활용하여 어떤 상품에서 에러가 발생했는지 로깅 및 추적합니다.
  • 대체 배너 이미지 경로: 대체 배너로 전환 시 노출되는 배경 이미지는 각 템플릿의 규격에 맞춰 {{HTTP}}/servlet/image/mobon/사이즈명.png (예: 300x250.png) 형태로 구성해야 합니다.

💅 5. 할인 상품과 일반 상품

유지보수의 편의성을 위해 할인 상품과 일반 상품의 파일은 하나로 통합되어 있습니다.
상태에 따른 UI 분기는 CSS 클래스를 통해 제어합니다.

  • UI 수동 확인 방법 (일반 배너): 할인 상품인 경우, 상품 가격을 감싸는 최상위 요소(.price_box)에 수동으로 .sale 클래스를 추가하여 확인합니다. 
    <!-- 일반 상품의 경우 -->
<div class="price_box">...</div>

<!-- 할인 상품의 경우 (.sale 추가) -->
<div class="price_box sale">...</div>
  • 동적 클래스 부여 (오토 프레임): 할인가(prdt_prmct) 데이터 존재 여부에 따라 ${isSale} 변수를 통해 자동으로 .sale 클래스를 렌더링합니다. 
    // 스크립트 내부 자동 분기 로직
const isSale = item.prdt_prmct ? "sale" : "";

// HTML 템플릿에 동적 바인딩
<div class="price_box ${isSale}">...</div>

✨ 6. 기타 공통 사항

  • 배너 규격 명시 (CSS 변수): 모든 HTML 파일 최상단 :root에 --width와 --height 변수가 선언되어 있습니다. 이는 임의로 변경하여 크기를 조절하기 위함이 아니라, 각 파일이 담당하는 배너 사이즈 규격을 명확하게 분리하여 관리하기 위한 목적입니다. 
    /* 설정 예시 */
:root {
    --width: 234px;
    --height: 60px;
}
